Record<string, { label: string; color: string }>
A TypeScript type for an object where keys are strings and values
are objects with specific fields. Useful for mapping enum values
to display properties like labels and colors.

Example use case: mapping job statuses to their Spanish labels
and CSS color classes so the table knows how to display each status.
