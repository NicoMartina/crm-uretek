# Git


**Start new work:**
* git checkout main
* git pull origin main
* git checkout -b feat/TICKET-NUMBER-description
* git push origin feat/TICKET-NUMBER-description

-------

**During work — commit as you go**
* git add .
* git commit -m "type: description"
* git push origin feat/TICKET-NUMBER-description

-------
**When done**

→ Open PR on GitHub.

→ Merge PR on GitHub.

→ Delete branch on GitHub

------
**Back locally**
* git checkout main
* git pull origin main
